# Крестики-нолики

Мой первый pet-проект на Python — консольная игра «Крестики-нолики» для двух игроков.

## Как запустить

Нужен Python 3. Запустите из папки проекта:

```bash
python game.py
```

Игроки ходят по очереди: введите номер строки и столбца от 1 до 3. Побеждает тот, кто первым соберёт три своих символа в ряд, столбец или по диагонали.

## Что использовано

- Python
- ООП: игровое поле реализовано в классе `Board`
- Создание пользовательских модулей и пакетов, разделение структуры проекта
- Type hints
